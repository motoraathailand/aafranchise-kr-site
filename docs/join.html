자주 묻는 질문

한국 이외 출시인가요?

아니요. 한국 전용입니다.

어떤 인증 테스트를 했나요?

브라우저에서 가짜 인증으로 로그인·동의·로그아웃 흐름을 확인했습니다. 실제 Google 계정 로그인은 확인하지 못했습니다.

APK 서명과 Firebase를 일치시켰나요?

전용 keystore로 APK를 서명했으며 등록 인증서와 일치하는지 확인할 수 있습니다.

금액은 추가할 수 있나요?

두 공식 API의 값이 개별 브랜드·법인에 일치하면 제공합니다. 인테리어 상세는 부담금 API를 이용할 수 없어 아직 제공하지 않습니다.

자동 갱신되나요?

GitHub Actions의 주간 검증을 통해 높은 버전일 때만 다운로드합니다.

운영비가 있나요?

자체 서버 없이 GitHub Pages와 사용자 AI 키를 사용하는 물례 등급입니다.
