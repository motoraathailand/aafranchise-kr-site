질문

비용은 몇 개 브랜드에 있나요?

첫 버전은 공식 목록의 비용 정보가 없어 금액을 넣지 않았습니다. 공식 공공데이터 API 키로 검증된 값이 있으면 보강할 수 있습니다. 업종 합계를 브랜드 금액으로 추정하지 않습니다.

어디에서 수집했나요?

공정거래위원회 가맹사업정보제공시스템의 공개 가맹사업 목록입니다. 공공 목록을 식별 User-Agent와 1.6초 이상 지연으로 요청합니다. 현재 robots.txt 응답이 오류 페이지라 목록 이외 탐색은 하지 않습니다.

왜 Google 로그인인가요?

Firebase Authentication으로 계정을 확인합니다. 설정에서 로그아웃하거나 계정을 삭제할 수 있습니다.

AI 키가 필요한가요?

AI 채팅에만 필요합니다. Gemini 키를 기기에 저장하고 질문할 때 선택한 공급자에만 본냅니다. 다른 기능은 키 없이 사용합니다.

지금 다운로드할 수 있나요?

초기 디버그 APK를 테스트용으로 준비했습니다. Play Store 출시·테스터 등록은 아직 없습니다.

브랜드 데이터가 앱을 망가뜨리면 어떻게 하나요?

스키마·버전·수·SHA-256 해시·기준일 등을 확인하고 잘못된 데이터는 기존 번들·저장본으로 교체하지 않고 유지합니다.

한국 이외 지역에서 사용할 수 있나요?

한국 프랜차이즈 창업만 대상으로 하며 출시 범위도 한국입니다.

매주 자동 갱신되나요?

GitHub Actions가 매주 월요일 오전 10시(방콕) 실행하며, 브랜드 다운로드는 버전이 높을 때뿐입니다.
